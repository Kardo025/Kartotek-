## Desktop app (the Windows installer)

The installer ships Electron, which bundles Chromium and Node.js. Electron is MIT licensed (Copyright (c) Electron contributors, Copyright (c) 2013-2020 GitHub Inc.). The licences of Electron and of the components of Chromium it contains are installed with the app, next to `Kartotek.exe`: `LICENSE.electron.txt` and `LICENSES.chromium.html`. Kartotek's own `LICENSE.txt` and this file are in the `resources` folder of the install. The installer is built with electron-builder (MIT), which is a build tool and not part of the installed app.
