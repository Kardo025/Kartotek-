1Core principles and the memory model

Goal: without notes, explain the main principle and the target band, tell S, D and R apart, and calculate the next interval with I = 9S(1/R* − 1).

K1 · Core principles of retrieval and spaced repetition p. 1–2

  • Main principle: estimate the current state of memory → choose the time that reaches the target recall at the lowest review cost → update the model with every answer.
  • Retrieval, not rereading: active recall before the answer is shown; the main signal is the right/wrong retrieval outcome.
  • No universal single interval: the further away the use, the longer the intervals should generally be.
  • Inverted U: too short an interval → little extra benefit; too long an interval → failed retrieval.
  • Hard but solvable: the practical goal is to keep recall probability in the ≈ 80–90% band.

R changes over time; D and S are updated after reviews. The state is kept separately for each user–card pair.

K3 · The forgetting curve and the target interval p. 4, 14–15

R(t, S) = (1 + t / 9S)⁻¹ R(S, S) = 0.90
I_target = 9 · S · (1/R* − 1)
  • S = 30 d, R* = 0.90 → I = 30 d · R* = 0.85 → I ≈ 47.65 d
  • Lower R* → longer interval, less review load. R* is not “higher is always better”; it balances load against the risk of forgetting.

Part summary: The main signal is retrieval; the interval–benefit relation is an inverted U and the target band is ≈ 80–90%. Card state is kept with S, D, R. R(t,S) = (1 + t/9S)⁻¹, R(S,S) = 0.90; I = 9S(1/R* − 1).

2Updating after an answer and handling failure

Goal: without notes, convert ratings into (y, q), calculate the new S after a failure, and tell apart the consecutive-failure policy and the types of failure.

K4 · Rating conversion p. 15

again00.0Could not recall / wrong

Ratings are not accepted blindly: with a median of 4 s, an “easy” after 25 s is treated as good or hard.

K5 · Stability update p. 8, 17–18

Success: G = exp(w0 − w1·D − w2·ln(1+S) + w3(1−R) + w4(q−1)); S′ = clip(S_min, S_max, S(1+G))
w0 = 1.4 · w1 = 0.08 · w2 = 0.25 · w3 = 1.0 · w4 = 0.35
Failure: S′ = max(S_min, S · [f0 − f1(1 − R)]) f0 = 0.55 · f1 = 0.15
  • Growth: difficulty ↑ → lower · current S ↑ → lower · success at low R → higher · quality ↑ → higher.
  • Example: S = 20 d, R = 0.85 → S′ = 20 × [0.55 − 0.15 × 0.15] = 10.55 d.
  • Failure does not reset the card; it keeps the history and accepts that the earlier estimate was too optimistic.

K6 · Consecutive-failure policy and types of failure p. 7, 9, 23–24

ConsecutiveAlgorithmic responseInterface response
1S drops, relearningCorrect answer; ask again in 10 min
2S more conservative, D rises“Would you like to add a hint?”
3Quality reviewSplit the card / study the underlying concept
4+Intervention instead of automatic reviewSuspend / tutorial mode
  • Real forgetting: no answer; lowers S the most.
  • Partial recall: lighter penalty, a better hint.
  • Confusion: a comparison card.
  • Misunderstood information: explanation, example, counterexample.
  • Card design error: split the card.
  • Attention-related error: interpret cautiously.
Part summary: again/hard/good/easy → q = 0 / 0.6 / 1.0 / 1.3. Success grows S with G; failure lowers it with S′ = max(S_min, S[f0 − f1(1−R)]) but does not reset it. Consecutive errors escalate to a content intervention; a failed card is a “card needing extra support”.

Glossary

Retrieval
An active attempt to recall without seeing the answer; the main signal.
Stability (S)
The number of days for R to drop to 0.90.
Difficulty (D)
How hard the card is to recall for this person (1–10).
Retrievability (R)
Current estimated recall probability (0–1).
Target retention (R*)
The recall probability at which the card should be shown again.
Quality factor (q)
The numerical value of the rating passed to the model.
Relearning
The short-interval recovery stage of a forgotten card.
Inverted U
The shape of the relationship between interval and benefit.
